# ⏳ Age Calculator

A simple, responsive, and easy-to-use Age Calculator web application built with HTML, CSS, and JavaScript. It calculates the exact age in years, months, and days based on the user's date of birth.

## 🔗 Live Demo
Check out the live application here: [Age Calculator Live Link](https://age-calculator-ten-delta-71.vercel.app/) 

## 🚀 Features
- Calculates exact age in years, months, and days.
- Interactive and modern user interface.
- Responsive design for mobile and desktop screens.
- Instant validation for future dates or invalid inputs.

## 🛠️ Built With
- **HTML5** - For structural markup
- **CSS3** - For styling, layout, and responsiveness
- **JavaScript (ES6)** - For core age calculation logic
